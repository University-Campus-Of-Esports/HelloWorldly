## A practical definition

**Artificial intelligence (AI)** describes computer systems designed to perform tasks associated with human abilities, such as recognising an object, understanding a request, finding a useful pattern or choosing an action. An AI system does not need to copy a human mind. It needs to produce a useful result for a task that involves some form of judgement, prediction or generation.

AI systems often receive an input and produce an output. A photo application might receive pixels and output the names of objects it detects. A translation tool receives text in one language and generates text in another. A fraud detector receives details of a payment and estimates whether it looks unusual.

## AI and conventional software

In conventional software, a programmer commonly writes precise rules. For example:

```text
if account_balance is less than purchase_price:
    reject the purchase
```

The same input and rules produce a predictable result. By contrast, many AI systems learn statistical patterns from examples. A programmer does not list every feature of every possible fraudulent payment. Instead, a learning process builds a **model** from historical examples. That model then estimates the likelihood that a new payment is fraudulent.

The boundary is not perfect. Real applications often combine fixed rules with AI models. A navigation application can use fixed road rules alongside AI predictions about traffic. AI is therefore a component or approach, not magic sprinkled over an entire product.

Common applications include speech recognition, medical image support, recommendations, game characters and tools that generate text or images. Their abilities vary greatly, and every output should be judged in the context in which it will be used.
